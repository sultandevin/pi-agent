# Pi Agent Setup

My minimal Pi Agent setup to use with the Ollama Cloud plan.

## Plugins

For the time being the setup is relatively simple:
- Caveman for token efficiency
- Subagents for delegating tasks

## Getting Started

### Installation

```bash
git clone https://github.com/sultandevin/pi-agent.git ~/.pi/agent
cd ~/.pi/agent
```
